# GODFIN architecture decisions

Accepted decisions are binding unless replaced by a newer ADR. A replacement
must name the superseded ADR and preserve migration/recovery consequences.

| ADR | Decision |
| --- | --- |
| [0001](0001-local-app-cloud-boundary.md) | Local desktop app and separate website boundary |
| [0002](0002-exact-money-and-sqlite.md) | Exact money and local SQLite authority |
| [0003](0003-schema-lifecycle.md) | Ordered startup migrations; no Alembic |
| [0004](0004-oauth-boundaries.md) | Separate website and desktop OAuth clients |
| [0005](0005-lifetime-licensing.md) | Lifetime commerce and signed entitlements |
| [0006](0006-private-release-promotion.md) | Signed private candidates before promotion |
